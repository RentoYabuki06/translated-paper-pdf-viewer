# 038 接続の表示を、題名の行の右端に置く

## 1. 目的

`note/037_menu.md` では、接続の表示(`llama-server(...) — 接続済み: ...`)を、倍率の右に置きました。
利用者から、題名(翻訳論文 PDF ビューア)と同じ行の右寄せにしてほしい、という依頼がありました。

## 2. 変更内容

| ファイル | 内容 |
| --- | --- |
| `src/App.tsx` | 題名と接続の表示を、1 つの行に並べた |
| `src/viewer/PdfViewer.tsx` | 操作の帯と、開く操作の行から、接続の表示を消した |
| `src/index.css` | 題名の行の指定 |
| `README.md` | 接続の表示の位置の説明 |

## 3. 設計判断

- 題名の行は、どの画面にもあるので、接続の表示も、どの画面にも出るようになりました(`note/037_menu.md` では、「PDF を開く」の画面だけでした)。
- PDF を開く前と後で、位置が変わらなくなりました。
- 幅の狭い画面では、接続の表示が、題名の下の行に折り返します。

## 4. 動作確認

環境は、macOS 26.6(Apple M5)、Chrome 157 です。`npm run dev` のページで確かめました。

- `npm test`: 479 件すべて成功。
- `npm run build`: 成功。
- arXiv 1706.03762 を開いた画面で、接続の表示が、題名と同じ行にあり、右端が本文の幅の右端にそろっていました。接続の表示は、画面に 1 つだけでした。

# 013 本文が Computer Modern の論文での確認と、数式による行送りの広がりの修正

## 1. 目的

`note/012_inline-math.md` で作った文中の数式の処理を、本文のフォントが Computer Modern の論文で確かめます。
この場合、数式の中の括弧や数字が本文と同じフォントで書かれるため、数式の範囲を広げる規則が最も働きます。
012 の時点では、見本の 2 本がどちらも本文が Times 系で、この場合を単体テストでしか確かめていませんでした。
確認で見つかった誤りも直します。

## 3. 設計判断

### 数式による行送りの広がり

- 訳文の中の数式は、行の中に置いた箱です。箱の上端や下端が、文字の行の範囲から少しでもはみ出すと、ブラウザはその行の高さを広げます。添字の付いた数式は、0.2 ポイントから 0.5 ポイントほどはみ出します。その結果、数式のある行だけ行送りが広がり、6 行の訳文の高さが、72 ポイントのはずが 75 ポイントになりました。
- 訳文の箱は、原文の範囲より少し(文字の大きさの 0.35 倍まで)下へ出ることを許しています(`note/011_pdf-translation.md`)。段落の間に空きが無い組版では、この 3 ポイントで、訳文の最後の行が次の段落の 1 行目に重なりました。
- 対処として、数式の箱のうち、文字の行の範囲からはみ出した分を、負の余白にして、行の高さの計算から外しました。外す上限は、上下それぞれ文字の大きさの 0.22 倍です。文字の行の範囲は、基準線の上 0.95 倍、下 0.22 倍としています。
- 上限を超えてはみ出す数式(分数など)では、超えた分だけ行送りが広がります。これは、これまでと同じです。
- はみ出した分は、上下の行の余白に重なります。原文の組版でも、添字は行送りを広げずに、行の余白に入っています。
- 選ばなかった方法は、訳文の箱が下へ出る許容(0.35 倍)を無くすことです。無くすと、原文と同じ行数の訳文が「収まらない」と判定され、必要のない段落で文字が小さくなります。

### 依頼の数の表示

- 翻訳を止めると、進み具合の表示の「依頼」が 0 件に戻っていました。数を、翻訳の実行中の状態と一緒に持っていたためです。止めたあとも残るように、文書の状態として持つようにしました。次に翻訳を始めるときに、0 に戻します。

### 数式の範囲(Node.js 上、7 ページ目)

数式を目印に置き換えた原文と、それぞれの目印に対応する数式の文字を、段落ごとに出力して見ました。

- 本文と同じフォントの括弧、数字、等号を含む数式が、1 つの範囲になっていました。集合と数を括弧で囲んだもの、不等号でつないだもの、括弧の中にコンマがあるもの、等号と近似の記号が続くものなどです。
- 上付きの脚注の番号は、1 つずつの範囲になっていました。
- 脚注の番号で終わる行の次の行が数式で始まる箇所で、番号と数式が 1 つの目印にまとまりました。行をまたぐ数式をまとめる規則が働いたためです。表示では、番号と数式が続けて置かれるので、そのままにしています。

### 翻訳と表示(ブラウザ、7 ページ目)

- 7 ページ目を表示した状態で翻訳を始めると、30 秒後に 562 単位のうち 56 単位が訳され、失敗、訳し直し、原文のまま残した単位は、どれも 0 件でした。
- 7 ページ目で、括弧や数字を含む数式が、原文と同じ見た目の 1 つの切り抜きとして訳文に入っていました。独立した数式(番号の付いた数式など)は、訳されずに元の描画のまま残っていました。
- 修正の前: 6 行の訳文の箱の高さは 75 ポイントで、下端(281)が次の段落の箱の上端(278)を越え、最後の行が次の段落の 1 行目に重なって見えました。
- 修正のあと: 同じ訳文の箱の高さは 72 ポイントで、下端が次の段落の箱の上端と一致し、重なりは無くなりました。

### 翻訳の中止

- 翻訳の途中で「中止」を押すと、表示が「翻訳が終わりました: 117 / 562 段落」になり、待っている単位と翻訳中の単位の印が 0 個になり、ボタンが「この PDF を翻訳する」に戻りました。`note/011_pdf-translation.md` では未確認だった操作です。
- 依頼の数は、修正の前は 0 件と表示され、修正のあとは、止めた時点の数(12 件)が表示されました。

## 5. 注意点・残課題

- 節の見出しと本文で、同じ語の訳語が違う箇所がありました。段落ごとに独立して訳しており、文脈を渡していないためです(`note/011_pdf-translation.md` の残課題)。
- 数式が行の余白に重なる上限(0.22 倍)は、見本の 1 ページで決めた値です。行送りがもっと狭い組版では、数式が上下の行の文字に触れる可能性があります。

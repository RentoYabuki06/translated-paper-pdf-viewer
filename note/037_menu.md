# 037 画面の切り替えをメニューの中に移し、接続の表示を倍率の横に置く

## 1. 目的

利用者から、次の 2 点の依頼がありました。

- 画面の上の、切り替えのボタンの行(PDF を開く、文章を貼り付けて訳す、用語集、翻訳サーバー)は不要。左のメニューの中に移して、ふだんは隠す。
- 同じ行にあった接続の表示(`llama-server(...) — 接続済み: ...`)は、倍率のプルダウンの横などに出す。

## 2. 変更内容

| ファイル | 内容 |
| --- | --- |
| `src/App.tsx` | 切り替えのボタンの行を消した。3 本線のボタンと、左のメニューを、ここに移した。メニューに、画面の切り替えと、履歴を置く場所を並べた |
| `src/viewer/PdfViewer.tsx` | 3 本線のボタンと、一覧の枠を消し、履歴の一覧を、メニューの中の場所に描くようにした。接続の表示を、操作の帯の倍率の右に置いた |
| `src/viewer/ConnectionBadge.tsx` | 新規。接続の表示を、`App.tsx` から移した |
| `src/index.css` | メニューの見た目。切り替えのボタンの行の指定を消した |
| `README.md` | 画面の切り替えと、接続の表示の位置の説明 |

## 3. 設計判断

- メニューは、`note/035_history.md` と `note/036_history-menu-button.md` で作った左の一覧を、そのまま広げました。上に画面の切り替え、下に履歴が並びます。
- メニューと 3 本線のボタンは、`App.tsx` に移しました。以前は「PDF を開く」の画面の中にあり、ほかの画面では出ませんでした。画面の切り替えを入れたので、どの画面でも出る必要があります。
- 履歴の一覧は、いままでどおり `PdfViewer.tsx` が持ち、メニューの中の場所へ描きます(React の `createPortal`)。履歴のデータと、選んだ PDF を開く処理が、`PdfViewer.tsx` にあるためです。
- メニューは、閉じている間も、要素を残して隠すだけにしました。履歴を描く場所が、無くならないようにするためです。
- 履歴から PDF を選ぶと、メニューを閉じて、「PDF を開く」の画面に切り替えます。ほかの画面から選んだ場合も、開いた PDF が見えます。
- 接続の表示は、PDF を開いたあとは、倍率の右に出します。PDF を開く前は、操作の帯そのものが無いので、開く操作の行の右に出します。接続できないことに、PDF を開く前に気付けるようにするためです。
- 接続の表示は、「PDF を開く」の画面にだけ出ます。以前は、どの画面にも出ていました。

## 4. 動作確認

環境は、macOS 26.6(Apple M5)、Chrome 157 です。`npm run dev` のページで確かめました。

- `npm test`: 479 件すべて成功。
- `npm run build`: 成功。
- PDF を開く前の画面に、切り替えのボタンの行が無く、接続の表示が、開く操作の行の右にありました。
- arXiv 1706.03762 を開くと、接続の表示が、倍率の右に出ました。
- 3 本線のボタンを押すと、メニューに、4 つの画面の名前と、履歴 1 件が出ました。いまの画面(PDF を開く)に、印が付いていました。
- メニューで「用語集」を選ぶと、画面が切り替わり、メニューが閉じました。
- 用語集の画面でメニューを開き、履歴から PDF を選ぶと、「PDF を開く」の画面に戻り、メニューが閉じ、「翻訳が終わりました: 104 / 104 段落」と表示されました。
- 接続の表示を押すと、翻訳サーバーの画面に切り替わりました。

## 5. 注意点・残課題

- いまどの画面にいるかは、メニューを開かないと分かりません(「PDF を開く」以外の画面には、それぞれの見出しや入力欄があります)。
- 「文章を貼り付けて訳す」「用語集」「翻訳サーバー」の画面には、接続の表示が出ません。
- メニューの外を押しても、メニューは閉じません。「×」で閉じます。

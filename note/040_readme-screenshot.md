# 040 README の先頭に、アプリの画面の画像を載せる

## 目的

GitHub でリポジトリを見た人に、アプリが何をするものかを、文を読む前に伝える。
そのために、原文と訳文のページを並べた画面の画像を、README の先頭に載せる。

## 変更内容

- `docs/screenshot.png`(新規): アプリの画面の画像。大きさは 1176 × 1025 画素、約 440 KB。
- `README.md`: 題名のすぐ下に、画像と、2 行の説明と、写っている論文の出典を加えた。
- `README.md`: 「ディレクトリの構成」の `docs/` の行に、画像のファイルを加えた。

## 設計判断

- 写す論文は、arXiv 2210.03629(ReAct)にした。
  - 画像には、論文の 1 ページ目の全文と、その訳文が写る。そのため、複製と翻案を認めるライセンスの論文を選んだ。arXiv のページで、この論文のライセンスが CC BY 4.0 であることを確かめた。
  - これまで動作の確認に使ってきた arXiv 1706.03762 は、arXiv の既定のライセンス(配布を arXiv に認めるだけのもの)なので、使わなかった。
  - CC BY 4.0 は、出典の表示と、変更を加えたことの表示を求める。README には、著者、題名、arXiv の番号、ライセンス、右のページが機械翻訳であることを書いた。
- 画面は、「原文を左に並べる」を入れ、倍率を 100% にした状態で撮った。
- 撮るときに、ページ全体を 88% に縮めた(`document.documentElement.style.zoom`)。開発に使っているブラウザの窓の幅(1130 画素)に、2 ページ(1224 画素)が収まらなかったためである。ブラウザの表示の縮小と同じ見え方になる。アプリのコードは変えていない。
- 画像の形式は PNG にした。文字の輪郭がにじまないためである。

## 動作確認

- arXiv 2210.03629 を開き、115 段落すべての翻訳が終わったことを、画面の表示で確かめた。
- 1 ページ目で、題名、要旨、見出し、本文の段落、脚注に訳文が入っていることを、画像で確かめた。
- `npm run build` が通ることを確かめた。
- 未確認: GitHub の上での README と画像の表示。
- 未確認: 2 ページ目以降の訳文の入り方。

## 注意点・残課題

- 画像の中の接続の表示は、古い別名(`plamo-3-translate`)である。`npm run model` で起動し直すと、表示は `plamo-3-translate-2b-Q4_K_M` に変わる。
- 訳文の題名は、「REAC T:」のように、字の間が空いて表示されている。
- 見本の論文を選ぶ途中で、次の 2 本を開いた。どちらも、一部の段落が英語のまま残った。原因は調べていない。
  - arXiv 2201.11903(1 段組): 1 ページ目の要旨と、2 ページ目の図の横を回り込む段落が、英語のまま残った。
  - arXiv 2302.13971(2 段組): 1 ページ目の本文の多くが英語のまま残り、左の段の下で、訳文が原文に重なった。倍率を 150% にしても、並べる表示を切っても、同じだった。
- この 3 本は、開いた PDF の履歴に加わった。

# 005 生成速度の実験スクリプト

## 1. 目的

既定のモデルの大きさ(2B か 8B か)は、手元の Mac(Apple M5)での生成速度を測ってから決めます。
その測定を 1 コマンドで行えるようにします。
あわせて、実物のモデルが無くても開発と動作確認ができるよう、llama-server の応答形式をまねる模擬サーバーを用意します。

## 2. 変更内容

| ファイル | 内容 |
| --- | --- |
| `scripts/probe-speed.ts` | 速度の実験。段落を訳させ、同時依頼数ごとの生成速度を表にする |
| `scripts/mock-llama-server.ts` | 模擬サーバー。原文の先頭に「【訳】」を付けて、少しずつ送り返す |
| `scripts/data/mathSentences.ts` | 実験で訳させる、数式を含む英語の文 60 件 |
| `scripts/lib/paragraphs.ts` | 文のひな形への数式の埋め込みと、段落の組み立て |
| `scripts/lib/pool.ts` | 同時に実行する数を制限しながら、非同期の処理を並行して行う補助関数 |
| `scripts/lib/stats.ts` | 合計と中央値 |
| `scripts/lib/cli.ts` | スクリプト共通の、エラーの表示と引数の解釈 |
| `tests/scripts/pool.test.ts`、`tests/scripts/data.test.ts` | 上記の単体テスト 17 件 |
| `package.json` | コマンド `probe:speed` と `mock` を追加 |

使い方は次のとおりです。

```
npm run model -- 2b      (別の端末で)2B を載せた llama-server を起動する
npm run probe:speed      速度を測る
```

8B を測る場合は、llama-server を `npm run model -- 8b` で起動し直してから、同じコマンドを実行します。

出力される表の列の意味は次のとおりです。

- 全体の速度: 生成したトークンの合計を、かかった時間で割った値。同時に走る依頼を合わせた処理能力を表します。
- 1 依頼の速度: 各依頼について llama-server が報告した生成速度の中央値。
- 1,000 トークンあたりの秒数: 全体の速度で 1,000 トークンを生成するのにかかる秒数。
- 上限で停止: 生成の上限に達して、訳文が途中で切れた依頼の数。

## 3. 設計判断

- 実験用の文は、この実験のために書き起こしました。論文の文は使っていません。公開リポジトリに他人の文章を載せないためです。計画では「実際の文」としていましたが、この点を変更しています。数式の文字列は、PDF から文字として取り出した場合の見え方(添字が平らに並び、記号が Unicode の文字になる)を模しています。
- 速度の測定に使う段落は、上記の文を 5 件ずつつなげて作ります。速度の測定では、段落の内容のつながりは結果に影響しないと判断しました。
- モデルの切り替えは、スクリプトでは行いません。llama-server の起動と停止を利用者が行う形にして、スクリプトを単純に保ちました。
- 模擬サーバーは、訳文として原文をそのまま返します。目印(タグ)が残る応答になるため、次の実験(目印が訳文に残る割合の測定)の動作確認にも使えます。

## 4. 動作確認

- `npm test`: 57 件すべて成功(本機能の 17 件と、既存の 40 件)。
- `npm run build`: 成功。
- 模擬サーバーに対する `npm run probe:speed`: 最後まで実行でき、同時依頼数ごとの表と訳文の例を表示。終了コードは 0。
- サーバーの同時処理数を超える同時依頼数を指定した場合: その行を省略する旨を表示。
- サーバーが無い場合: 接続できない旨と起動方法の案内を表示し、終了コード 1 で終了。
- 指定が不正な場合(同時依頼数に 0): 1 行の案内を表示し、終了コード 1 で終了。
- 実物の llama-server に対する測定: 未実施。llama.cpp が未導入のためです。

## 5. 注意点・残課題

- 模擬サーバーが返す速度の値は見かけ上のもので、実物の性能とは関係がありません。
- 実験用の文は自作のため、実際の論文の文より素直な構文に偏っている可能性があります。実際の PDF から取り出した段落での確認は、PDF の解析を実装したあとに行います。
- 1 ページあたりの翻訳時間は、この表からは直接出ません。実測した「1,000 トークンあたりの秒数」と、1 ページの訳文のトークン数から見積もります。

# 029 原文のページと、訳文のページを、横に並べて表示する

## 1. 目的

利用者から、元の論文と、翻訳後のページを、横に並べながら読みたい、という依頼がありました。
これまでは、訳文を元のページに重ねて表示し、原文は、段落をクリックして切り替えて見る作りでした。
原文と訳文を、同時に見られる表示を足します。

## 2. 変更内容

| ファイル | 内容 |
| --- | --- |
| `src/viewer/PdfViewer.tsx` | 「原文を左に並べる」のチェックボックスを追加。入れると、ページごとに、原文のページを左に、訳文を重ねたページを右に並べる |
| `src/index.css` | 並べたページの配置。並べている間は、本文の幅の制限を外して、画面の幅いっぱいを使う |
| `README.md` | 「PDF を翻訳する」の操作の表に、1 行を追加 |

## 3. 設計判断

- 左のページは、既にあるページの部品(`PageView`)を、訳文と確認用の枠を重ねない指定で、もう 1 つ置いたものです。新しい部品は作っていません。
- 解析とレイアウト検出の結果は、開いた PDF ごとに 1 か所で持っているので(`session.ts`)、ページを 2 つ置いても、解析は 1 回です。描画は、左右で 1 回ずつ行います。
- 左右は、同じ倍率、同じ高さで並べます。同じ段落が、左右の同じ位置に来ます。
- 選ばなかった方法は、左右を別々に上下へ送れる 2 つの枠にする方法です。読む位置を左右でそろえる操作が、利用者の手間になります。
- 2 ページ分の幅は、本文の幅の上限(72rem)に収まらないことがあります。並べている間は、ページの並びだけ、画面の幅いっぱいを使います。
- 倍率は、自動では変えません。

## 4. 動作確認

環境は、macOS 26.6(Apple M5)、Chrome 157 です。

- `npm test`: 467 件すべて成功。`npm run build`: 成功。
- `npm run dev` のページで、arXiv 1706.03762 を開き、保存してある訳文で翻訳を済ませてから、倍率を 100% にして、「原文を左に並べる」にチェックを入れました。
  - 15 ページすべてが、左に原文、右に訳文の 2 ページずつの行になりました。
  - 1 ページ目の行では、左のページに訳文は 0 件、右のページに訳文は 4 件でした。
  - 幅 1,460 画素の画面で、行の幅は 1,240 画素で、横にはみ出しませんでした。
  - ブラウザのコンソールに、エラーと警告は出ませんでした。

### 未確認

- 倍率 150% 以上で、画面の幅を超える場合の、横に送る操作。
- チェックを外して、もとの表示に戻す操作。
- 2 段組の論文での表示。
- 並べた状態での、描画にかかる時間とメモリ。

## 5. 注意点・残課題

- 並べている間は、ページの描画が 2 倍になります。
- 左のページでも、表示中のページの判定(翻訳の順番に使うもの)が行われます。左右は同じページなので、結果は変わりません。

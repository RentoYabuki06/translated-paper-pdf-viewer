# 036 履歴を開くボタンを、左上の 3 本線のボタンにする

## 1. 目的

`note/035_history.md` では、履歴を開くボタンを、「PDF のファイルを選ぶ」の左に、文字のボタンとして置きました。
利用者から、左上に表示するハンバーガーメニュー(3 本線)のボタンにしてほしい、という依頼がありました。

## 2. 変更内容

| ファイル | 内容 |
| --- | --- |
| `src/viewer/PdfViewer.tsx` | 「履歴(件数)」のボタンを消し、3 本線のアイコンのボタンを足した |
| `src/index.css` | ボタンを、画面の左上に固定する指定 |
| `README.md` | 「履歴から開き直す」の節の、ボタンの説明 |

## 3. 設計判断

- ボタンは、画面の左上に固定しました。下へ送っても、同じ位置に残ります。ページを読んでいる途中でも、別の PDF に切り替えられます。
- ボタンは、「PDF を開く」の画面にだけ出ます。履歴は、この画面の機能で、ほかの画面(用語集など)から開いても、選んだ PDF が見えないためです。
- 件数は、ボタンには出さず、マウスを重ねたときの説明と、読み上げ用の名前に入れました。
- 一覧を閉じる操作は、一覧の右上の「×」と、同じ 3 本線のボタン(一覧の下に隠れます)のままです。

## 4. 動作確認

環境は、macOS 26.6(Apple M5)、Chrome 157 です。`npm run dev` のページで確かめました。

- `npm test`: 479 件すべて成功。
- `npm run build`: 成功。
- arXiv 1706.03762 を開き、1500 画素ぶん下へ送った状態で、ボタンが、画面の左上(上から 12 画素、左から 12 画素)にありました。
- ボタンを押すと、一覧が開き、1 件が表示されました。「×」を押すと、閉じました。
- 「PDF のファイルを選ぶ」の行から、文字の「履歴」のボタンが無くなりました。

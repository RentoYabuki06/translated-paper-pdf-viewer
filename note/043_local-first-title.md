# 043 題名と README で、自分のパソコンの中で完結することを打ち出す

## 目的

「翻訳論文 PDF ビューア」という題名だけでは、このアプリの特徴が伝わらない。
翻訳が自分のパソコンの中で完結することを、題名と README の先頭で伝える。

## 変更内容

- `src/App.tsx`: 題名を「ローカル完結の翻訳論文 PDF ビューア」にした。題名の下に、1 行の説明「論文を外部に送らず、自分のパソコンの中だけで翻訳します」を加えた。
- `src/index.css`: 題名と説明の行の見た目(`.app-title`、`.tagline`)を加えた。
- `index.html`: ページの題名を同じ名前にした。ページの説明(`meta name="description"`)を加えた。
- `docs/architecture.svg`: 図の題名(`title` の要素)を同じ名前にした。図の見た目は変わらない。
- `docs/screenshot.png`: 新しい題名の画面で撮り直した。撮り方は note/040 と同じ。
- `README.md`: 題名を同じ名前にした。題名のすぐ下に、太字の 1 行と、次の 2 つの一覧を加えた。
  - 自分のパソコンの中で完結するもの(翻訳、PDF の読み取りとレイアウト検出、保存、利用の登録が要らないこと)
  - インターネットに接続する場合(モデルのファイルの取得、arXiv からの PDF の取得)

## 設計判断

- 名前は、もとの「翻訳論文 PDF ビューア」を残し、前に「ローカル完結の」を付けた。もとの名前で覚えている人にも、同じアプリだと分かるためである。名前は、利用者に選んでもらったものではなく、こちらで決めた。
- リポジトリの名前(`translated-paper-pdf-viewer`)と、`package.json` の `name` は変えていない。URL と、複製したあとのフォルダーの名前が変わるためである。
- README には、インターネットに接続する場合も書いた。「完結する」とだけ書くと、モデルの取得のときにも接続しないと読めるためである。
- 「原文を送る先は 127.0.0.1 だけ」には、「既定の設定では」を付けた。翻訳サーバーの URL は、設定で書き換えられるためである。
- インターネットに接続する先は、`src/` の中の URL を検索して確かめた。見つかったのは、arXiv(`src/pdf/arxiv.ts`)と、レイアウト検出のモデルを取得する Hugging Face(`src/layout/ortWebClient.ts`)だった。翻訳のモデルは、llama-server が Hugging Face から取得する。

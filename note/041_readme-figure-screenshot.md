# 041 README に、図のあるページを並べた画像を加える

## 目的

図を含むページでも、図が元の見た目のまま残り、文章だけが訳されることを、README の先頭で見せる。
依頼は、arXiv 1706.03762(Attention Is All You Need)のアーキテクチャ図のあたりを、原文と訳文を並べて写すことだった。

## 変更内容

- `docs/screenshot-figure.png`(新規): 3 ページ目の Figure 1 とその前後を、原文と訳文を並べて写した画像。大きさは 1568 × 588 画素、約 164 KB。
- `README.md`: 1 枚目の画像の説明の下に、この画像と、2 行の説明と、写っている論文の出典を加えた。
- `README.md`: 「ディレクトリの構成」の `docs/` の行に、画像のファイルを加えた。

## 設計判断

- 写す範囲は、ページの全体ではなく、Figure 1、図の題名、その下の 1 段落までにした。
  - この論文のライセンスは、arXiv の既定のもの(配布を arXiv に認めるだけのもの)で、CC BY ではない(note/040)。
  - 論文の 1 ページ目には、出典を示すことを条件に、報道や学術の著作物で表と図を複製することを Google が認める、という注記がある。
  - 注記が認めているのは表と図なので、本文が写る量を小さくした。README には、著者、題名、arXiv の番号、注記の内容、右が機械翻訳であることを書いた。
- この画像には、アプリのボタンの行は写っていない。3 ページ目まで下に送ると、ボタンの行は画面の外に出るためである。ボタンの行は、1 枚目の画像に写っている。
- 撮り方は 1 枚目と同じで、「原文を左に並べる」を入れ、倍率を 100% にし、ページ全体を 88% に縮めた。

## 動作確認

- arXiv 1706.03762 を開き、保存してあった訳文で 104 段落すべてが表示されたことを、画面の表示で確かめた。
- 画像で、図が左右で同じ位置に同じ見た目で写り、図の題名とその下の段落が日本語になっていることを確かめた。
- `npm run build` が通ることを確かめた。
- 未確認: GitHub の上での README と画像の表示。

## 注意点・残課題

- README がこの注記の「報道や学術の著作物」に当たるかどうかは、確かめていない。当たらないと判断した場合は、この画像と、README の該当の段落を消す。
- 画像を切り出すときに、上下が約 7 画素ずつ切れた。見え方に影響はない。
